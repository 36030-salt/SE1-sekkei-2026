サギョウツリー
今作業してるフォルダ、見えているファイル
↓git add
ステージ
変更をまとめてコミットするためのエリア
↓git comit
リポジトリ
コミットしたファイルを保存するとこ


add  変更をステージエリアに追加
comit　変更を記録
push　コミットしたやつをリポジトリ送りにする
pull　リモートリポジトリの変更をローカルに取り込む

git config(--globalなし)
$ git init

$ git add jikosyoukai.md
（かごに入れる）
$ git add .
（変更した全部を入れる）
$git comit -m"自己紹介を作成"
-mを忘れるとエディタが開いてしまう
